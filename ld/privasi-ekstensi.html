Kebijakan Privasi Ekstensi Chrome "Aventra Leads: Catat Chat Iklan"

Berlaku sejak 25 November 2026

Ringkasan

Ekstensi ini membantu bisnis yang beriklan mencatat chat calon pelanggan yang datang dari iklan. Ekstensi membaca WhatsApp Web di browser pengguna hanya untuk mencari kode promo yang dibuat oleh Aventra Leads (contoh MR-K7M2QX). Ekstensi tidak pernah mengirim pesan WhatsApp dan tidak berafiliasi dengan WhatsApp atau Meta.

Data yang diproses

  • Isi chat yang tampil di layar WhatsApp Web dibaca di perangkat pengguna untuk mencari kode promo. Isi percakapan tidak disimpan dan tidak dikirim.
  • Hanya untuk chat yang berisi kode promo, ekstensi mengirim ke akun Aventra Leads milik bisnis: kode promo, nomor WhatsApp dan nama profil pelanggan, nomor WhatsApp CS yang menerima, dan waktu.
  • Data akun: email dan token login Aventra Leads, disimpan di penyimpanan lokal ekstensi untuk menjaga sesi login.
  • Bila pengguna (paket Pro) mengubah tahap, alasan, atau menandai Lunas dari panel, perubahan itu dan nilai order dikirim ke akun Aventra Leads.

Cara data digunakan

  • Menampilkan laporan iklan, chat, dan closing di dashboard Aventra Leads milik bisnis tersebut.
  • Bila diaktifkan oleh bisnis, mengirim event Lead dan Purchase ke Meta Pixel/Conversions API milik bisnis itu sendiri. Nomor telepon dikirim dalam bentuk hash SHA-256.
  • Data tidak dijual, tidak dipakai untuk iklan pihak ketiga, dan tidak dipakai untuk tujuan lain di luar fitur di atas.

Penyimpanan & keamanan

  • Data disimpan di database Aventra Leads (Supabase) dengan akses terbatas per bisnis (row level security). Hanya anggota bisnis tersebut yang dapat melihatnya.
  • Semua pengiriman data memakai koneksi terenkripsi (HTTPS/TLS).
  • Data lead disimpan selama akun bisnis aktif. Bisnis dapat menghapus data lead kapan saja dari dashboard, atau meminta penghapusan seluruh data melalui kontak di bawah.

Pilihan pengguna

  • Ekstensi baru bekerja setelah pengguna menekan Setuju & lanjut di layar izin.
  • Pengguna dapat mematikan "Catat otomatis", mencabut izin, atau keluar kapan saja dari menu ekstensi. Menghapus ekstensi menghapus seluruh data lokalnya.
