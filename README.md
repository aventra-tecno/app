# aventra-tecno.github.io  →  app.aventra.id

Repo akar domain aplikasi Aventra.
- `CNAME` berisi `app.aventra.id` (domain khusus untuk semua repo GitHub Pages akun ini).
- `index.html` / `404.html`: app.aventra.id/ dan alamat yang tidak dikenal dialihkan ke https://aventra.id
- `.well-known/assetlinks.json`: bukti kepemilikan aplikasi Android (TWA). Isi dari ZIP PWABuilder.
- Aplikasi ada di repo lain: repo `app` → app.aventra.id/app/sp/ (Stok Gudang), aplikasi baru → app.aventra.id/app/<nama>/
Jangan upload signing.keystore atau signing-key-info.txt ke repo mana pun.
